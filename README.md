# NCK

Website PT. NUSA CIPTA KREASI — Kami Produksi, Kamu Beraksi.

Website memperkenalkan produk jersey sublimasi, kaos DTF, sablon plastisol, jasa printing, serta layanan dropship dan private label.

## Menjalankan secara lokal

Jalankan server statis dengan direktori `dist`, misalnya:

```sh
python3 -m http.server 8765 --directory dist
```

Buka http://localhost:8765.

## Struktur

- `dist/index.html`: konten website
- `dist/style.css` dan `dist/carousel.css`: tampilan responsif dan identitas visual
- `dist/app.js`: penyusun pesan konsultasi WhatsApp
- `dist/assets/`: logo, font, foto, dan motif garis
- `.openai/hosting.json`: konfigurasi hosting Sites
